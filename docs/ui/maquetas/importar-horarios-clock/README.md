# Maqueta de importación de horarios laborales

Maqueta interactiva de CU1 en el proyecto MagicPath **KUME — Diseño administrativo · Paso 4**. Proyecto `467706881381666816`, componente **Horarios laborales · Importar desde Clock** `475948353407041536`, revisión compilada `475948353407041537`.

En Administración → Horarios laborales, abrir «Importar desde Clock». Vincular «Turno tarde revisado» a «Turno tarde», crear otra referencia o dejarla pendiente. La confirmación muestra el resultado y permite volver a importar para observar las coincidencias. Los datos son ficticios y el catálogo de la maqueta vive en memoria. Esta revisión presenta la importación y las correspondencias. La edición del inicio y fin locales se definió después y sigue pendiente de incorporar a la maqueta.
